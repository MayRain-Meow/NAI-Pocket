# NAI Pocket 体验与手机调试

可先在电脑预览里熟悉界面，再用与源码配套的 **0.3.7 preview APK** 检查手机行为。0.2.x 内置 12,866 位画师的完整选定名单，原作例图资料包不随项目分发，可导入自备资料；早期 0.1.0 APK 没有包含这些功能。当前仍是预览版，真机和付费生成尚未验证。

## 电脑上先看这些

已有预览链接时，直接打开即可。在源码中自行启动：

```sh
cd app
npm ci
npm run preview:offline
```

打开终端显示的本机地址，选择「窄屏 360」或「手机 412」。不需要 Android Studio。按下面顺序体验：

1. 打开「画师」，搜索 `anmi`，查看三张例图和每张图下的标注。默认预览使用合成图；只有显式载入选定资料的预览才显示真实原作，页面会注明。
2. 查看作品来源、AI 初标／人工确认和缺少标注的提示，试试按标注筛选。确认图片与标注对应、长文字能读完、返回后能继续浏览。
3. 收藏画师、填写本机备注、点击「加入画风」，检查结果是否符合预期。
4. 在设置中切换官方／RBQ，再试编辑器、队列、图库和恢复参数。预览只接受页面提供的演示凭据，生成是模拟操作。

浏览器预览中的 Android 文件选择、资料网络下载和系统导出不执行真实操作。资料包目录、下载进度和版本校验有自动化检查，仍需下面的手机验收。

## 手机上的检查顺序

拿到待验收 APK 后，先完成不产生生成费用的项目：

1. 安装配套 APK，检查键盘弹出、底部按钮、安全区、系统返回键，以及关闭再打开应用。
2. 在「设置 → 画师标注资料」点「读取目录」，再下载全部分包（约 79 MB，不含图片）；打开画师时例图从 Danbooru 读取。本项目不分发画师原图。有自备资料时，可用「导入资料包」选择 ZIP，或填写自己的资料目录链接；资料下载不需要生成 Token。
3. 下载中取消一次，再重新下载。确认取消后已有资料仍可读，成功后显示已安装版本。也可用「导入资料包」选择提前下载的 ZIP。
4. 关闭网络，重新打开画师详情，确认已下载的例图、对应标注和本机备注可用。选定资料中 11,431 位画师至少有三张带标注例图；其他画师可能不足三张或没有标注，界面应明确显示缺失，AI 初标应保留原状态。
5. 测试资料更新中断和应用重启：旧版资料仍可使用，未完成的新版不应显示为已安装。下载期间先保持应用在前台；目前重试会重新下载。
6. 导入一张本机 PNG，检查参数读取、图库和图片导出；把方案、片段和画师收藏／备注导出为备份。图片与 Token 不在此备份中。

真实生成放在最后：由账号所有者选择 Token、渠道和参数，并明确同意消耗后，只发起一次小批量请求。检查队列、通知、退到后台再恢复、完成后的图片保存，以及重启后没有自动重复提交。RBQ 使用 RBQ 凭据；涉及官方 Vibe 编码时，按提示明确选择官方账号并确认消耗。不要把浏览器演示结果当成这一步通过。

## 出问题时怎样反馈

记录「APK 版本、手机型号与 Android 版本、所在页面、操作步骤、实际结果」。截图保留错误文字即可，不必复制 Token 或整份数据库。画师问题同时注明画师名、例图位置、资料包 ID 和版本。

需要开发者协助查看设备时，可在 Android 开发者选项中开启 USB 调试，用数据线连接电脑，并在手机上确认本次电脑授权。电脑安装 Android SDK Platform Tools 后运行 `adb devices -l`：显示 `device` 才是已连接，`unauthorized` 表示手机尚未授权，空列表表示尚未识别设备。连接本身不会安装 APK 或发起生成。
